# Hardware Empire: descargas

Hardware Empire es un juego de gestión para Windows en el que diseñas CPUs entre 1971 y 1995: dibujas el floorplan del die, ajustas la microarquitectura, haces el tape-out y compites contra los chips reales de cada época.

Este repositorio solo contiene las versiones publicadas del juego, no su código.

## Cómo instalarlo

1. Entra en [la última versión](../../releases/latest).
2. Descarga `Hardware-Empire-Setup-<versión>.exe` y ábrelo.
3. El juego no tiene firma digital, así que Windows SmartScreen puede avisar la primera vez: pulsa **Más información** y luego **Ejecutar de todas formas**.

Se instala solo para tu usuario y no pide permisos de administrador. Crea accesos directos en el escritorio y en el menú Inicio, y se puede desinstalar desde **Configuración → Aplicaciones instaladas**. Desinstalarlo no borra tus partidas.

**Actualizaciones:** el juego instalado busca versiones nuevas al abrirse. Si encuentra una, la descarga y te pregunta si quieres reiniciar ahora o aplicarla al cerrar.

**Versión portable:** el `.zip` no necesita instalación. Descomprímelo y abre `Hardware Empire.exe`. Esta versión no se actualiza sola.

Requisitos: Windows 10 u 11 de 64 bits.
